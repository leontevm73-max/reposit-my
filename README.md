# ГЛИНА — лендинг гончарной студии

Одностраничник на Tilda для гончарной студии в Москве: мастер-классы и курсы по керамике с нуля.

**Демо:** [marketplacewave22.tilda.ws/page362320909.html](https://marketplacewave22.tilda.ws/page362320909.html)

## Блоки
- **Hero** — заголовок, подзаголовок, кнопки «Выбрать программу» / «Записаться»
- **Преимущества** — 3 карточки: малые группы, всё включено, изделие домой
- **Программы** — «Первый круг» 2 500 ₽, «Курс новичка» 9 800 ₽, «Своя посуда» 24 000 ₽
- **Галерея** — работы учеников с лайтбоксом (стрелки, Esc)
- **Контакты + форма** — адрес, часы, телефон, email, Telegram, форма заявки

## Стек
Tilda · HTML/CSS/JS в блоке **T123** · без фреймворков и сборки.  
Стили и скрипты изолированы в `#glina` — не конфликтуют с другими блоками Tilda.

## Структура
text

## Как править
1. Tilda → Pages → нужная страница → блок T123
2. Вставьте/отредактируйте код
3. Сохраните и опубликуйте

> В T123 не нужны `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>` — Tilda оборачивает сама.

## Адаптив
Галерея 4→3→2 колонки; Hero и контакты — в один столбец на ≤800 px; фото галереи на мобильных — 150 px.
